# Ration Shop Management System

## 📌 Overview

The Ration Shop Management System is a web-based application designed to manage customer details, ration card types, and distribution processes efficiently.
This system helps streamline operations in a ration shop by digitizing manual tasks.

---

## 🚀 Features

* Add and manage customer details
* Assign ration card types (APL, BPL, AAY)
* Maintain structured records
* Simple and user-friendly interface

---

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS
* **Backend:** PHP
* **Database:** Oracle Database
* **Server:** XAMPP (Apache)

---

## ⚙️ How It Works

1. User fills the customer form
2. Data is sent to the server using POST method
3. PHP processes the request
4. Data is stored in Oracle Database
5. System displays updated records

---

## 💻 Setup Instructions

1. Install XAMPP and start Apache
2. Place the project folder inside:

   ```
   C:\xampp\htdocs
   ```
3. Configure Oracle Database connection in your PHP files
4. Run the project in browser:

   ```
   http://localhost/ration_shop
   ```
